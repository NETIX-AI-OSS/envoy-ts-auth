# Contributing to auth

Thanks for contributing to `auth`.

## Workflow

1. Fork the repository to your own GitHub account or organization.
2. Create a focused branch from `main`.
3. Make minimal, reviewable commits.
4. Open a pull request with clear context, test notes, and docs updates.

## Development Setup

```bash
yarn install
yarn build
yarn docs
```

## Pull Request Expectations

- Keep changes scoped and purposeful.
- Update docs when behavior, config, or API usage changes.
- Add or update tests when applicable.
- Avoid introducing unrelated refactors.

## Commit and PR Quality

- Write descriptive commit messages.
- Include motivation, behavior change, and risk in PR description.
- Add screenshots or logs when relevant to debugging/integration behavior.

## Code of Conduct

By participating, you agree to follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
