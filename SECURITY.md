# Security Policy

## Supported Versions

Security fixes are prioritized for the latest release line maintained in the default branch.

## Reporting a Vulnerability

Please report vulnerabilities using **GitHub Security Advisories** only:

1. Open the repository on GitHub.
2. Go to the **Security** tab.
3. Click **Report a vulnerability** to submit a private advisory draft.

Do not open public issues for undisclosed vulnerabilities.

## Response Process

- Maintainers will acknowledge valid reports as quickly as possible.
- We will coordinate remediation details privately through the advisory thread.
- Public disclosure and patch notes will follow once a fix is available.
